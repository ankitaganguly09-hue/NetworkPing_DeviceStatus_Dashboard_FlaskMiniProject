# NetworkPing_DeviceStatus_Dashboard_FlaskMiniProject

A simple Flask-based mini project that monitors whether devices on a network are online or offline using the **Ping** command.

This project helps beginners understand:

- Flask basics
- Backend + Frontend integration
- Routing
- Form handling
- Dynamic HTML rendering
- Running system commands using Python

---

# Features

- Add Device
- Ping Device using IP Address
- Show Device Status Dashboard
- Refresh Status Button
- Online/Offline Status Display

---

# Technologies Used

| Technology | Purpose |
|---|---|
| Python | Backend programming |
| Flask | Web framework |
| HTML | Frontend structure |
| CSS | Styling |
| Jinja2 | Dynamic HTML rendering |
| subprocess | Running ping command |
